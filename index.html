Caltiki Repository

Pronostici calcio per Kodi. Si installa come qualunque altro addon: niente account, niente chiavi da inserire.

Installazione

  1. In Kodi: Impostazioni → Sistema → Add-on e attiva Origini sconosciute.
  2. Impostazioni → Gestione file → Aggiungi sorgente → <Nessuno>, e scrivi questo indirizzo: https://caltiki.github.io/pronostici-repo/ Dai alla sorgente il nome caltiki.
  3. Add-on → Installa da file zip → caltiki → repository.pronostici.zip.
  4. Add-on → Installa da repository → Caltiki Repository → Add-on video → Pronostici Calcio → Installa.
Al passo 4 Kodi scarica da solo anche i loghi delle squadre: sono un pacchetto a parte da 18 MB, quindi quel passaggio impiega qualche secondo in piu' degli altri. Da qui in avanti gli aggiornamenti arrivano da soli.
